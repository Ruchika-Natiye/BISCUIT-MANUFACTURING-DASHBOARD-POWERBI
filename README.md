# 📊 Project Overview

<p>
The Biscuit Manufacturing Dashboard is an interactive business intelligence project developed using Microsoft Power BI. It provides a comprehensive overview of biscuit manufacturing operations through data visualization and analytical reporting.

The dashboard helps understand production performance, sales trends, product-level performance, and key business metrics to support data-driven decision-making.
 
</p>

# 🎯 Project Objectives
<p>

1. Analyze biscuit manufacturing and business performance.

2. Monitor key performance indicators (KPIs).

3. Understand product-wise performance.

4. Identify sales and production trends.

5. Compare business performance across different categories.

6. Generate meaningful insights through interactive visualizations.

  
</p>

# 📈 Key Dashboard Features

**1.** KPI Cards: Quick overview of important business metrics.

**2.** Sales Analysis: Analyze sales performance and trends.

**3.** Production Analysis: Monitor manufacturing performance.

**4.** Product Analysis: Understand product-wise contribution.

**5.** Interactive Filters: Explore data using slicers and filters.

**6.** Visual Analytics: Present complex business information through charts and graphs.
